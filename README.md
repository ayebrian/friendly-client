# Friendly Client

Приватный TypeScript/React клиент для существующей сети Friendly. TypeScript включён в strict-режиме. Первый работающий срез:
вход по email, профиль, уведомления со счётчиком, прочтение и просмотр ответа.

```sh
npm ci
npm run dev
```

Открыть адрес из вывода Vite (обычно http://localhost:5173). Кнопка «Открыть демонстрацию» запускает изолированный
адаптер с примерами данных. В нём можно добавить новое событие на странице профиля
и увидеть обновление счётчика и сообщение. Демо не отправляет запросы в Friendly.

Реальный вход использует почту, уже привязанную к аккаунту Friendly. Код — 8 цифр.
Без аккаунта реальная авторизация и содержимое уведомлений не проверены.
Базовый URL по умолчанию https://api.getfriend.ly; переопределение через
`VITE_API_BASE_URL` в `.env.local` (это публичная настройка, не место для секретов).

## Структура проекта

- `src/app` — сборка приложения, провайдеры и маршруты.
- `src/domain` — типы и контракт API, без зависимостей от UI.
- `src/infrastructure` — настоящий API, проверка ответов, сессия и отдельный демо-адаптер.
- `src/features` — экраны и логика входа, уведомлений, профиля и обсуждения.
- `src/shared` — готовые UI-компоненты и общие состояния.

Экраны реализованы в TSX. `index.html` — входная точка Vite.

## Готовые библиотеки

- shadcn/ui (Radix): кнопки, поля, вкладки, меню аккаунта, подсказки, аватары,
  бейджи и состояния загрузки. Общие компоненты лежат в `src/shared/ui`.
- Tailwind CSS 4: оформление компонентов; цвета, типографика и радиусы задаются
  одной темой в `src/app/styles.css`.
- React Hook Form + Zod: формы и проверка ввода.
- Sonner: уведомления внутри окна со ссылкой на события.
- TanStack Query: запросы, кеш и синхронизация; React Router: маршруты;
  Lucide: иконки.

Добавить готовый компонент: `npx shadcn@latest add dialog` (или другой компонент).
`components.json` направляет генератор в общую библиотеку; бизнес-логика остаётся
в features. Библиотеки подключаем под рабочий сценарий, а не целиком заранее.

## Медиа в публикациях

В редакторе поста, ответа и редактирования кнопка **Media** открывает выбор нескольких
файлов. Фото/GIF, видео и аудио можно также вставить в поле из буфера обмена (Ctrl+V
на компьютере, вставка из клавиатуры на Android). Кнопка **Paste** доступна в браузерах,
которые поддерживают чтение медиа из буфера по запросу пользователя.

Лимит клиента — 10 вложений, до 5 MB на файл. Превью и удаление доступны до отправки;
пост можно отправить без текста. Файлы загружаются при отправке. При ошибке черновик
сохраняется, повторная отправка использует уже загруженные файлы. Уход со страницы,
выход и истечение сессии отменяют загрузку. В демо медиа остаются внутри сессии.

Редактор использует rich contenteditable с вводом обычного текста, поскольку Chromium
предлагает Android-клавиатуре вставку изображений только в richly editable поле.
Обрабатываются `paste` и `beforeinput` без привязки к клавишам. Проверены настоящая
вставка Ctrl+V и сценарий событий Android в Chromium на 1440/360px; физическое
устройство с Gboard не проверено.
